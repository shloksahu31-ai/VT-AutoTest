## 8. Restore

### 8.1 Restore a single file or folder

```powershell

Copy-Item "$b\e2e\tools\..." "C:\path\to\target" -Recurse
```

```powershell
cd "C:\Users\shlok\Desktop\Work\Vacature Tovenaar"

```

### 8.3 Reconstruct the whole pre-cleanup working tree

```powershell
$src = "C:\Users\shlok\Desktop\Work\Vacature Tovenaar\_BACKUPS\vacature-tovenaar-testing_2026-11-02_2026"
$dst = "C:\Users\shlok\Desktop\Work\Vacature Tovenaar\restored"
robocopy "$src\repo" $dst /MIR
cd $dst
git apply "$src\working-tree-diff.patch"   # replay uncommitted tracked changes
npm ci
copy .env.e2e.example .env.e2e             # then fill in real values
npx playwright install chromium
```

Do not restore on top of the cleaned repository unless that is intentional — the
cleaned tree is the supported state.

### 8.4 Restore secrets

`.env.e2e` in the backup contains the live UAT credentials and TOTP secret. Copy
it only to a trusted machine, and never commit it.
